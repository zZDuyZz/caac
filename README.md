# CAAC — certified, compute-adaptive control of LLM reasoning

For each question, a controller chooses among **answering now** (small model,
greedy), **sampling more** (small model, majority vote), **escalating** to a
larger model that writes a new answer, or **abstaining**. The goal is the
lowest expected cost per question subject to a **certified** bound on the error
rate of the answers it serves: the whole multi-stage policy is one configuration,
certified in a single Learn-then-Test (LTT) pass. Cost never enters the test:
it orders the actions a policy tries and picks among certified configurations,
so the guarantee holds at each price ratio between the models, and a family
that never reads the price is certified once for all of them. Every baseline
goes through the same certification protocol.

What the controller estimates is **recoverability**, not confidence. A
selective cascade asks whether its current answer is trustworthy; this asks
whether the next action would actually repair a wrong answer, which of the
available repairs is cheapest, and when no repair is worth its price -- so a
question nothing can fix is abstained on *before* the expensive tier is billed
rather than after. The value of an action is therefore net,

    Delta_a = P(correct after a) - P(correct now) = P(gain_a) - P(harm_a),

because escalating or re-voting can also lose an answer the small model had
right. The vote CAAC serves counts the greedy answer as one vote and never counts
a sample cut off by the token cap (`voting.py`); baselines keep the plain majority. `recovery_table.py` measures where failures sit (four rescue groups, and
three cost-dependent regions: repairable cheaply, only expensively, or not at
all within this action set and sample budget), and `certify.py` runs the
net-value gates (net gain, net gain per unit of extra cost, and the same gate
asked again at every state with the evidence already bought) and the
confidence gate as arms of the same policy so the
comparison is in the results rather than in the design.

The repository follows one rule: **the GPU generates a sample pool once;
everything else runs offline on CPU** by replaying that pool (policies,
baselines, calibration, certification, cost accounting).

## Models and engine

| Role | Small → big | Notes |
|---|---|---|
| Main pair | `Qwen/Qwen3.5-2B` → `Qwen/Qwen3.5-9B` | thinking OFF, text-only |
| Second family | `meta-llama/Llama-3.2-1B-Instruct` → `meta-llama/Llama-3.1-8B-Instruct` | gated on the Hub |
| Size axis | `Qwen/Qwen3.5-0.8B`, `Qwen/Qwen3.5-4B` → `Qwen/Qwen3.5-9B` | model gap from about 2× to 11× |
| Pilot (`outputs/a2/`) | `Qwen/Qwen2.5-1.5B-Instruct` → `Qwen/Qwen2.5-7B-Instruct` | vLLM 0.7.3, engine V0 |

Pools are built with **vLLM 0.32.0 (engine V1)** in a Python 3.12 virtualenv;
every pool's manifest records the engine, library versions, GPU, seeding,
logprobs mode and chat-template arguments. One model = one GPU type and one
configuration for all of its pools.

## Install

```bash
pip install -e ".[dev]"            # CPU: replay, estimators, certification, tests
pip install -e ".[data,dev]"       # + benchmark loaders and the Math-Verify grader
pip install -e ".[plot]"           # + matplotlib for chow_frontier.py
python -m pytest -q                # all tests run on CPU, no network
```

GPU pool building is set up by `session2_setup.sh` (it creates the venv and pins
the engine); do not install the `gpu` extra into a CPU environment.

## Building the pools (GPU, Session 2)

```bash
cd /workspace && git clone https://github.com/zZDuyZz/caac.git && cd caac
# 0) token caps: probe train questions at a high cap, read cap_curve.txt
tmux new -s caac 'TAG=v3 STOP_AFTER=capprobe bash session2_all.sh 2>&1 | tee -a /workspace/s2.log'
# 1) setup, smoke (small AND big model), parameter count, test pools, determinism
tmux new -s caac 'TAG=v3 MT_M=<cap> MT_G=<cap> STOP_AFTER=test_pools bash session2_all.sh 2>&1 | tee -a /workspace/s2.log'
# 2) same command without STOP_AFTER -> train/calibration pools (A3) and hidden states (A4);
#    on a fresh machine copy the two tarballs to /workspace and run `bash session2_restore.sh v3` first
tmux new -s caac 'TAG=v3 MT_M=<cap> MT_G=<cap> bash session2_all.sh 2>&1 | tee -a /workspace/s2.log'
```

Each stage leaves a marker file, so re-running the same command resumes. The run
ends with `outputs/s2_<TAG>/s2_summary.md` and `/workspace/s2_bulk_<TAG>.tar` (text and
per-token sidecars, hidden states — these are **not** committed to git).

All pools of one tag share one protocol, and the scripts enforce it rather than trust it:

- `env_reference.txt` lists the package versions of the first GPU day; `session2_setup.sh`
  compares every new machine with it (`check_env.py`) and re-pins what moved.
- `outputs/s2_<TAG>/protocol.lock` records the token caps, the context length and the GPU
  type of the tag's first run; a later run with other values stops before generating.
- `build_pool.py` refuses to resume a pool whose manifest disagrees with the current
  arguments, and repairs a file whose tail was cut by a kill before appending to it.
- The smoke test runs again on every machine, and when the test pools came from another
  machine a 150-question slice is regenerated and compared with them.

## Offline analysis (CPU)

```bash
# where do the failures sit? four rescue groups and three regions, per price ratio
python recovery_table.py --small P/math500_qs.jsonl.gz --big P/math500_qb.jsonl.gz \
    --k 16 --lams 1,1.5,4.5 --json out/recovery_math500.json
# every method certified under one protocol; train / calib / test share no question
python certify.py --train-small P/a3_math_train_qs.jsonl.gz --train-big P/a3_math_train_qb.jsonl.gz \
    --calib-small P/a3_math_test_ex500_qs.jsonl.gz --calib-big P/a3_math_test_ex500_qb.jsonl.gz \
    --test-small P/math500_qs.jsonl.gz --test-big P/math500_qb.jsonl.gz --alpha 0.10 --json out/math500.json
# GSM8K: no separate calibration pool, so the train pool is split in two by question id
python certify.py --train-small P/a3_gsm8k_train_qs.jsonl.gz --train-big P/a3_gsm8k_train_qb.jsonl.gz \
    --test-small P/gsm8k_qs.jsonl.gz --test-big P/gsm8k_qb.jsonl.gz --alpha 0.10 --json out/gsm8k.json
# does the certificate hold? violation rate over random calibration/test re-splits
python resplit.py --train-small P/a3_math_train_qs.jsonl.gz --train-big P/a3_math_train_qb.jsonl.gz \
    --pool-small P/a3_math_test_ex500_qs.jsonl.gz --pool-big P/a3_math_test_ex500_qb.jsonl.gz --splits 500
python chow_frontier.py --small P/math500_qs.jsonl.gz --big P/math500_qb.jsonl.gz --label "MATH-500" --out figs/chow --alpha 0.10
python run_baselines.py --small P/gsm8k_qs.jsonl.gz --big P/gsm8k_qb.jsonl.gz --json figs/baselines_gsm8k.json
python verify_params.py --weights Qwen/Qwen3.5-2B --weights Qwen/Qwen3.5-9B   # exact sizes for the FLOPs axis
```

`certify.py` sweeps the price ratio `lam` (one big-model token costs `lam`
small-model tokens) and, at each value, reports every method's most-coverage
pick, its cheapest pick at each target coverage, the plug-in rule without a
test, the oracle, and which method is cheapest where (the phase map).

## Layout

| Path | What it is |
|---|---|
| `build_pool.py` | the one GPU artifact: greedy + n samples per question, graded, with text and per-token sidecars (resumable) |
| `extract_hidden.py` | question-only hidden states for the stage-0 probe |
| `regrade_pool.py`, `compare_pools.py`, `smoke_check.py`, `s2_summary.py` | re-grading, determinism check, smoke gate, session summary |
| `make_qids.py`, `qids/` | stratified question ids for the calibration/train splits |
| `certify.py`, `resplit.py` | the main comparison under one certification protocol, and its validity check |
| `recovery_table.py` | which action repairs a wrong answer, and at what price: the rescue groups and regions the allocation claim rests on |
| `chow_frontier.py`, `train_estimator.py`, `run_baselines.py` | the Chow ceiling, a stand-alone estimator fit, the always-answer sweep |
| `verify_params.py` | parameter counts (config formula, or exact from safetensors headers) checked against the cost registry |
| `session2_*.sh` | one-command GPU session |
| `src/caac/pool/` | pool schema with label-free answer classes, policies, method families, the certification protocol, estimators (pre-action, net value, after sampling, after escalation), recoverability and state-conditioned value estimators, the served vote, the expected-cost model, LTT, Chow frontier, adaptive-sampling baselines, cost ledger |
| `src/caac/data/`, `src/caac/eval/` | benchmark loaders (incl. clean sets), the single chat prompt, answer matching, Math-Verify grading, calibration metrics |
| `outputs/a2/` | pilot pools (Qwen2.5), kept for the appendix |

Older code (the within-trajectory controller, the original experiment harness,
the P3 oracle tree) was removed on 2026-11-06; it is preserved in git history at
tag `pre-cleanup-2026-11-06`.
